# Data attribution

This directory mixes two sources:

## `cuad/` — Contract Understanding Atticus Dataset (CUAD)

50-document subset of CUAD v1, redistributed under **CC BY 4.0**.

- Source: https://zenodo.org/records/4595826
- Citation: Hendrycks, D. et al. *CUAD: An Expert-Annotated NLP Dataset for Legal Contract Review*, 2021.
- License: Creative Commons Attribution 4.0 International

The subset was extracted by `scripts/download_cuad.py` from the official Zenodo release zip.

## `synthetic/` — Synthetic contract chains

Generated by `src/synthetic_contract_generator.py`. No real-world contract text; all party names, scopes, and amounts are fictional. Used to exercise hierarchical MSSA → SOW → Change Order relationships that CUAD does not naturally contain.

Regenerate with:

```bash
python -c "from pathlib import Path; import sys; sys.path.insert(0, 'src'); from synthetic_contract_generator import build_chain, render_chain; [render_chain(build_chain(seed=s), Path('data/synthetic')) for s in [11, 22, 33]]"
```
